Vereins Manager

Login

Schritte für das Login:

  1. Öffne eine Web-Browser-Instanz (z.B. Google Chrome, Mozilla Firefox) auf deiner lokalen Maschine.
  2. Füge die URL http://localhost in die Adressleiste ein und drücke Enter.
  3. Dies sollte dich zum Startseite-Ansicht führen, auf dem du links eine Form für das Login sehen solltest.
  4. Eingabe deines Benutzernamens (Username) und Passworts in die entsprechenden Felder.
  5. Klicke den Button "Login" an, um deine Anmeldung zu bestätigen.

Schritte für die Registrierung:

  1. Wenn du nicht bereits angemeldet bist, wirst du zur Startseite weitergeleitet werden.
  2. Auf der rechten Seite findest du eine Form für das Registrieren.
  3. Eingabe deines Benutzernamens (Username) und Passworts in die entsprechenden Felder.
  4. Klicke den Button "Register" an, um deine Registrierung zu bestätigen.

Allgemeine Verwaltung

Klicken Sie auf den Button "Vereins Logo hochladen" in der Mitte der Seite.

  1. Wählen Sie das Bild aus, das Sie als Vereinslogo verwenden möchten.
  2. Klicken Sie auf "Öffnen".
  3. Klicken Sie erneut auf den Button "Vereins Logo hochladen", um das Hochladen des Bildes abzuschließen.

Das ist alles! Ihr neues Vereinslogo sollte nun auf Ihrer Seite erscheinen.

Mannschaftskasse

Klicken Sie auf den Button "Neue Transaktion hinzufügen" in der Mitte der Seite, um eine neue Transaktion zu erstellen.

  1. Wählen Sie den Typ der Transaktion (Einnahme oder Ausgabe) aus dem Dropdown-Menü.
  2. Eingabe des Betrags in die entsprechende Eingabefeld. Stellen Sie sicher, dass das Datum korrekt verarbeitet wird.
  3. Beschreibung der Transaktion in den Textfeld.
  4. Klicken Sie auf "Speichern", um die Transaktion zu erstellen.

Dies ist alles! Ihre neue Transaktion wurde erfolgreich erstellt.

Trikotsatz

Wie man einen Trikotsatz hinzufügt:

  1. Wählen Sie den richtigen Trikot-Typ aus:
    • Auswärts
    • Heim
  2. Geben Sie die Anzahl an Trikots ein:

    3. Füllen Sie das Feld `trikotAnzahl` mit der benötigten Anzahl aus.

  3. Eingabe von Hosen-Informationen:
    • Angaben zur Anzahl an Hosen (`hoseAnzahl`) und deren Größe (`hoseGroesse`).
  4. Hinzufügen von Stutzen (optional):

    5. Füllen Sie das Feld `stutzenAnzahl` mit der benötigten Anzahl aus.

Nachdem alle Schritte ausgeführt wurden, klicken Sie auf den Button "Speichern", um den Trikotsatz hinzuzufügen.

Meldung von Trainingseinheiten

Zu erst muss ein Trainer vorhanden sein.
Um einen neuen Trainer hinzuzufügen, folge bitte den folgenden Schritten:

  1. Klicke auf "Neuen Trainer erfassen". Dieser Button befindet sich direkt unter dem Titel.
  2. Ausfülle das Formular mit den folgenden Informationen:
    • Vorname
    • Nachname
  3. Klicke auf den "Speichern"-Button, um die Informationen abzusenden.

Das Formular zur Eingabe neuer Trainer-Zeiten befindet sich hinter dem Button "Bearbeiten"

Schritt 3: Identifizierung der Bestätigung
