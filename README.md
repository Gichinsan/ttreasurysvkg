# ttreasurysvkg
Team treasury system for small soccer teams

User Rolen

**Admin**

Der Admin darf User verwalten also auch Rollenzuweisen 

**Kassenwart**

Der Kassenwart darf sehen allgemeine Verwaltung und Mannschaftskasse.
Die Kontonummer wird bei der Registrierung erzeugt und ist eine uuid.

**Trainer**

Trainer darf sehen Trikosatz, Team, Turnierplanung, Meldung Trainingseinheiten
